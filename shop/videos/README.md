# Videos for "Watch videos"

- `NN.mp4`: full clip with sound, played in the player.
- `preview/NN.mp4`: small silent loop (360px, up to 12 s) that plays inside the blob.
- `preview/NN.jpg`: still frame shown while the preview loads.

To add or replace a clip, update all three files and the list at the top of `shop/videos.js`.
